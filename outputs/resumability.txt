**Token‑Budgeting Cheat Sheet for AI Agents**

- **Define the budget up‑front**  
  - Set a hard limit (e.g., 4 K, 8 K, 32 K tokens) based on model pricing, latency constraints, and downstream costs.  
  - Split the budget into *input* vs. *output* caps (e.g., 60 % prompt, 40 % response) to avoid overruns.

- **Track token usage in real time**  
  - Instrument the agent to call `tiktoken.encode` (or the model‑specific tokenizer) after each prompt/response.  
  - Store cumulative counts in a session state object; raise a warning when > 80 % of the budget is reached.

- **Prioritize and prune context**  
  - Use a *sliding‑window* or *summarization* strategy: keep the most recent N turns, compress older turns into a concise summary, and discard irrelevant history.  
  - Apply selective retrieval: embed past documents, fetch only the top‑k most relevant chunks before tokenizing.

- **Dynamic budget allocation**  
  - Adjust the output length on the fly: if the remaining budget is low, set `max_tokens` to a smaller value and request concise answers.  
  - Offer fallback modes (e.g., “brief answer” vs. “full explanation”) when the budget cannot accommodate the original request.

- **Post‑processing safeguards**  
  - Trim trailing whitespace, stop‑token artifacts, and redundant phrasing before counting final tokens.  
  - Log each interaction (prompt, response, token count) to a monitoring dashboard for audit, cost forecasting, and future budget tuning.
